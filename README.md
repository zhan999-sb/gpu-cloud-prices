# GPU Cloud Prices

Source of https://gpu-cloud-prices.pages.dev, an independent, multilingual index of
public GPU cloud list prices (on-demand and Spot), refreshed automatically by GitHub Actions.

* Data: official public price APIs only for tracked providers (Azure Retail Prices,
  Linode/Akamai, Scaleway, Verda). Providers whose terms forbid price comparison are
  link-only and never scraped.
* Every published number is re-computed by an independent build-time audit.
* Price history lives on the `data` branch.

Some outbound links may be affiliate/referral links; they never affect rankings or prices.
